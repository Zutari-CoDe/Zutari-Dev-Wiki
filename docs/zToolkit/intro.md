## ZToolkit Overview

ZToolkit is a cross-platform toolkit designed to support computational design workflows within both **Autodesk Revit/Dynamo** and **Rhino/Grasshopper** environments.  
It provides a unified set of ZeroTouch nodes and Grasshopper components that simplify geometry processing, automate repetitive modeling tasks, and enhance interoperability across design applications.

This toolkit is maintained as a shared codebase with two parallel deliverables:

- **ZToolkit (Dynamo Package)** — A library of ZeroTouch nodes built for Dynamo Revit 2023, 2024, and 2025.  
- **ZToolkit.Grasshopper (GH Plugin)** — A Grasshopper plugin targeting Rhino 7 and Rhino 8.

Whether you're working in Dynamo or Grasshopper, ZToolkit aims to provide consistent, predictable behavior through clean APIs, well-structured utilities, and a versioned build process that aligns with the corresponding host application.
